## Wskazówki dla Nano Banana Pro

### Ustawienia Ogólne:
| Ustawienie | Wartość |
|------------|---------|
| **Styl** | Photorealistic / Professional Photography |
| **Rozdzielczość** | 8K / 4K |
| **Format** | 16:9 (landscape) dla głównych, 1:1 dla detali |
| **Oświetlenie** | Natural light / Soft studio lighting |
| **Tło** | White room / Clean indoor venue |
| **Depth of Field** | Shallow (bokeh) |

### Słowa Kluczowe dla Lepszych Wyników:

**Dodaj na końcu promptu:**
- `professional event photography`
- `shallow depth of field`
- `bokeh background`
- `glossy balloon surface`
- `photorealistic`
- `8K resolution`
- `ultra detailed`

**Unikaj:**
- `cartoon`
- `illustration`
- `drawing`
- `animated`
- `3D render`

### Kolory Brandu (dodaj do promptu jeśli potrzebne):
- `hot pink #FF6B9D`
- `turquoise #4ECDC4`
- `golden yellow #FFE66D`
- `purple #A855F7`

## Proces Generowania w Nano Banana Pro

1. **Wybierz styl:** Photorealistic / Photography
2. **Wklej prompt** (start z głównym promptem)
3. **Ustaw ratio:** 16:9 dla pełnej dekoracji
4. **Generuj** - jeśli nie idealne, doprecyzuj
5. **Dostosuj:** Dodaj/odejmij elementy w kolejnych próbach

### Przykładowe doprecyzowania:
- "Add more gold balloon accents"
- "Make the balloons more glossy"
- "Include balloon floor decorations"
- "Add balloon numbers for age"
- "Softer lighting, more natural"

## Po Generowaniu - Co zrobić ze zdjęciami?

1. **Zapisz** jako: `pirate-decoration.jpg`, `unicorn-decoration.jpg`, `jungle-decoration.jpg`
2. **Umieść** w: `public/images/`
3. **Dodaj** do `Gallery.tsx`:
```tsx
{
  id: 5,
  category: "urodziny",
  title: "Piracka Przygoda",
  gradient: "from-amber-500 to-orange-600",
  emoji: "🏴‍☠️",
  description: "Dekoracja na urodzinki małego odkrywcy",
  image: "/images/pirate-decoration.jpg",
},
```

## Lista Kontrolna Jakości

- [ ] Balony są błyszczące (nie matowe)
